# Meter Gomoku AI 训练器 — 连线版

Windows 桌面端五子棋助手。它会**视觉识别屏幕上正在对弈的棋盘**（任何第三方客户端或网页棋盘），把局面同步到内部小棋盘，调用 Rapfi 引擎思考，并可自动落子。本仓库为**连线（识图）版**——屏幕抓图 + 覆盖层 + 模拟点击，不是单机训练器。

## 功能特性

- **自动棋盘识别**：自动在屏幕上定位 15×15 棋盘；识别成功后锁定棋盘几何，只有用户手动点"重新识别"才会重新找棋盘（一般用户不会动棋盘位置）。
- **实时棋子识别**：锁定棋盘后按帧做差分识别棋子变化（快，约 50 ms 延迟）；棋子上的红 / 蓝 / 绿色选中圈一律视为"非棋子"并忽略。
- **引擎仪表盘**：深度、速度（节点/秒）、节点数、评分、最佳路线实时刷新；全程使用**单发独占 analyze 通道**，引擎把全部算力集中在一次搜索上。
- **规则**：无禁手（自由）、无禁手长连不赢、有禁手（连珠）。中途改规则 / 时间 / 线程 / 哈希，引擎会按当前局面重新计算。
- **平衡开局工具**：平衡点搜索与交换平衡评估，**有禁手 / 无禁手 / 长连不赢各用各的平衡线**（不混用定式）；结果以半圆环标记画在棋盘上（上半圆=序号，下半圆=分数），算完即停，把算力立刻还给主引擎。
- **线程 / 哈希持久化**：用户选的线程数和哈希大小会保存，下次打开自动恢复，并按本机核心数与内存自动适配。

## 目录结构

```
host/      Win32 C++ 宿主：棋盘扫描、识别 IPC、引擎进程、覆盖层窗口、模拟点击
           （host.cpp、engine_host.*、appver.* 等）
ui/        WebView2 前端（bridge.js、calc.js、calc.html、calc.css、engine-ai.js）
vision/    屏幕棋盘 / 棋子识别模块（基于 OpenCV）
core/      共享 JS 引擎核心胶水
rapfi/     Rapfi 搜索核心源码 + 随包引擎构建
           （见 rapfi/CMakeLists.txt；官方上游：dhbloo/rapfi）
Release/   预编译安装包（Meter Gomoku_Setup4.42.exe）
```

构建脚本、UI 加密工具和中间构建产物**按设计不纳入仓库**。安装包内的 UI 是加密的（`*.enc`）；`ui/` 下保留明文源码供阅读。

## 运行环境

- Windows 10 / 11（x64）
- [WebView2 运行时](https://developer.microsoft.com/microsoft-edge/webview2/)（Win11 已自带）
- 安装包已内置 Rapfi 引擎各指令集变体（SSE / AVX2 / AVX512 / AVX-VNNI）和网络模型；**运行不需要 Python 或 Node**。

## 从源码构建（参考）

使用工具链：MSVC 2022 (v143)、Windows 10/11 SDK、WebView2 SDK、静态 OpenCV。
- `host/` —— Win32 宿主工程（含 manifest、appver.rc、Calculator.ico 资源）。
- `vision/` —— 链接静态 OpenCV 构建为 DLL，导出函数供宿主调用。
- `rapfi/` —— 用 CMake preset 构建，按目标 CPU 选指令集变体。
- `ui/` 明文在打包时用本地工具加密成 `*.enc`（该工具不在本仓库）；宿主解密后交给 WebView2。

## 使用（快速上手）

1. 运行 `Meter Gomoku_Setup4.42.exe` 安装。
2. 打开你的五子棋客户端 / 网页棋盘。
3. 点**识别棋盘**（框选范围太小时"自动"会自动朝真实棋盘方向外扩）；锁定后内部小棋盘会跟着每一步走。
4. 在仪表盘选你执的色、规则和思考时间；打开**自动落子**即可让引擎回应。
5. 用**平衡点** / **交换平衡**做开局研究——下够指定手数后标记自动清除。
